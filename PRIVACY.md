# Privacidad de CF Calca Fácil

CF Calca Fácil está diseñada para funcionar localmente en el dispositivo.

- No requiere crear una cuenta.
- No contiene anuncios ni rastreadores.
- No envía fotografías, dibujos ni datos personales a servidores.
- Las imágenes elegidas se leen únicamente para mostrarlas durante el calco.
- La cámara se usa solo mientras el usuario mantiene activo un modo de cámara.
- El modo flotante no captura, copia ni guarda el contenido de otras
  aplicaciones.
- El usuario puede detener la cámara flotante desde su panel o desde la
  notificación permanente.

Al abrir los enlaces del panel principal, el navegador o Instagram reciben la
dirección pública elegida por el usuario conforme a sus propias políticas.

Esta descripción corresponde a la versión beta `0.2.2+4`.
