# Instalación del APK de CF Calca Fácil

CF Calca Fácil puede instalarse gratis directamente desde GitHub, sin utilizar Google Play.
Requiere Android 7.0 o una versión posterior.

## Descargar

1. Abre la página [CF Calca Fácil v0.2.2 beta](https://github.com/CFontalvo/cf-calca-facil/releases/tag/v0.2.2-beta.1).
2. En la sección **Assets**, descarga `CF-Calca-Facil-v0.2.2-beta.1.apk`.
3. Espera a que finalice la descarga antes de abrir el archivo.

No es necesario crear una cuenta de GitHub ni pagar para descargar el APK.

## Instalar en Android

1. Abre el APK desde las descargas del navegador o desde el administrador de archivos.
2. Si Android lo solicita, autoriza temporalmente la opción **Instalar aplicaciones desconocidas** para la aplicación desde la cual abriste el archivo.
3. Regresa al instalador y toca **Instalar**.
4. Abre CF Calca Fácil y concede únicamente los permisos necesarios para el modo que quieras utilizar.

El nombre exacto de las opciones puede cambiar según la marca del dispositivo y la versión de Android.

## Aviso de seguridad y versión beta

- Descarga el APK únicamente desde el repositorio oficial `CFontalvo/cf-calca-facil`.
- Esta es una versión beta firmada con un certificado local de desarrollo; no es una compilación publicada por Google Play.
- Android o el navegador pueden mostrar una advertencia porque el archivo proviene de fuera de Google Play.
- Puedes desactivar nuevamente el permiso **Instalar aplicaciones desconocidas** después de instalar la app.
- Si una futura beta utiliza una firma diferente, Android puede exigir desinstalar la versión anterior antes de instalarla.

## Permisos de la aplicación

- **Cámara:** para los modos de calco que utilizan la cámara trasera.
- **Mostrar sobre otras aplicaciones:** solo para la cámara flotante.
- **Notificaciones y servicio visible:** para indicar que la cámara flotante continúa activa.

CF Calca Fácil funciona localmente, no requiere cuenta y no envía tus imágenes a servidores. Consulta la [política de privacidad](../PRIVACY.md).
